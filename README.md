# 📚 Python + PostgreSQL + SQLAlchemy + Alembic (HW 6)

## 📌 Опис проєкту

Цей проєкт реалізує базу даних університетської системи з використанням:

- PostgreSQL (через Docker)
- SQLAlchemy ORM
- Alembic (міграції)
- Faker (генерація тестових даних)

---

## 📦 Сутності бази даних

Проєкт містить такі таблиці:

- **students** — студенти
- **groups** — групи студентів
- **teachers** — викладачі
- **subjects** — предмети (з прив’язкою до викладача)
- **grades** — оцінки студентів з датою отримання
